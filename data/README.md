# Data

This project uses a **synthetic logistics dataset** generated by `src/generate_data.py`.

No confidential, proprietary or real DHL operational data is used.

To generate the CSV from the repository root:

```bash
python src/generate_data.py
```

This creates:

```text
data/dhl_style_parcel_volume.csv
```

The generated dataset contains four fictional depots and daily observations from January 2024 to July 2026, including calendar, weather and parcel-volume fields.
